# 九牧智能马桶 Home Assistant 蓝牙桥接固件

通过 ESP32-C3 将九牧智能马桶接入 Home Assistant，支持在 HA 中控制，并可由 HA 自动化实现远程操作。

连接方式：Home Assistant → 家庭 Wi-Fi → ESP32-C3 → 蓝牙 → 马桶。

本项目为第三方适配，与九牧官方无隶属关系。仓库主要提供编译后的固件和使用文档；Release 同时附上与固件匹配的脱敏源码包及许可证。

## 支持型号

| 马桶型号 | 状态 | 说明 |
| --- | --- | --- |
| 九牧 SQ9650 | 已由使用者实机验证现有全功能版 | 已识别设备硬件 V05、固件 V1.26_ZQ6650；不同批次仍需核对 |
| 其他九牧型号 | 未验证 | 不承诺兼容；使用同一小程序不代表协议相同 |

桥接硬件已验证：ESP32-C3 SuperMini，4 MB Flash。其他 ESP32 开发板不能直接视为兼容此固件。

## 可控制功能

- 盖板：打开、关闭。
- 座圈：抬起、放下。
- 冲水：小冲、大冲。
- 夜灯：开启、关闭。
- 脚感开关：开启、关闭。
- 光感夜灯：开启、关闭。
- 座圈加热：常温、中温、高温。
- 魔力泡：启动。
- 马桶休眠：进入休眠；未实现可靠的远程唤醒命令，启用前需确认现场唤醒方法。
- 查询马桶状态、硬件版本和主板固件版本。

可读取盖圈状态、有人着座、盖圈运动、蓄水就绪、冲水/发泡状态等已解析字段。此固件不提供未经该型号证据确认的清洗、烘干等功能。

## 版本状态

现有全功能版已由使用者反馈全部功能实测可用。

按需蓝牙优化版已完成本地编译和代码审查，尚未进行现场验收：Wi-Fi 保持在线，操作时连接蓝牙，读回新状态后执行；完成后空闲 10 秒断开，多步操作期间保持连接。它的省电幅度和长期稳定性尚未测量，发布时应标记为测试版。

## 供电与安装

ESP32 放在马桶蓝牙覆盖范围内，以稳定 USB 电源供电；桥接方案不需要拆开马桶或接入马桶内部电路。避免金属遮挡，并在安装位置做好防潮。手机九牧小程序可能占用蓝牙连接，排查连接问题时先退出小程序。

## 刷入与配置

通用配置测试版 **v0.1.0-beta1** 已完成编译。请从 [Releases](https://github.com/guoyyyyyy/jomoo-toilet-ha/releases) 下载 factory.bin，核对 SHA256SUMS，按[使用与刷机](使用与刷机.md)操作。通用版配网与按需蓝牙尚待现场验收。

使用流程：下载对应 ESP32-C3 的出厂刷写镜像 → 通过 USB 刷入 → 设置自己的 Wi-Fi、目标马桶蓝牙地址 → 在 HA 添加 ESPHome 设备 → 先读取状态，再逐项测试控制。

不要使用他人的家庭固件、完整闪存备份或构建测试镜像。它们可能包含私人凭据，或使用不可连接的测试网络，也可能写死他人的马桶地址。

## Home Assistant

通过 ESPHome 集成接入。蓝牙按需待命时，不会持续回传遥控器或脚感造成的状态变化；控制前会重新读取。

现有自动化如将“蓝牙已连接”作为执行入口条件，使用按需版本时需调整为：先确认 ESP32 在线，再建立会话、等待有效状态，最后执行动作。断线期间显示的是历史状态。

## 反馈兼容型号

请提供马桶型号、设备硬件/固件版本、ESP32 型号、失败步骤及脱敏日志。不要公开 Wi-Fi 密码、API 密钥或完整闪存备份。未通过现场验证的新型号只列为待验证。

## 网络与安全边界

本公开测试版 API 和网页为无认证明文局域网接口，仅用于可信家庭局域网。初次配网热点 Jomoo-Setup 无密码，需在可信现场配置；不要将设备端口开放到公网。远程操作通过 HA 既有安全入口进行。本版不提供普通网页 OTA，更新使用 USB。
